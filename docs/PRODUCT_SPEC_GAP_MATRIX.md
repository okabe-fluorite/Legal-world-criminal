## 实施顺序（本地优先）

2. **切片B：预习/复习共用TaskAttempt（已完成服务端）。**学生可完成推荐题，服务端判分并生成不可变LearningEvent，更新画像并返回下一任务；困惑标注使用独立自报事件。
3. **切片C：学生端连续旅程（已完成核心）。**知识卷宗、困惑标注、预习/复习测验、精学入口、完成反馈和下一任务已共用现有Vue外壳。
4. **切片D：教师端最小形态（已完成核心）。**已增加显式角色/班级/选课，匿名聚合困惑、知识、能力、错误和事件；内容审核操作写不可变审计台账。
5. **切片E：实验与提交证据（机制审计/协议已完成）。**可信RAG和自适应软件机制消融、模型目录脱敏审计、证据分级与8—12人试点协议已完成；Agent/真实模型同条件消融和真实课堂试点仍待外部条件。

P1知识/论证图、私有媒体资产和媒体能力页已完成；ASR/服务端TTS/视觉接口已预留但Provider仍为`not_connected`。P2数字人只完成异步契约、AI标识和肖像同意门禁，仍依赖外部授权，不进入核心阻塞路径。
