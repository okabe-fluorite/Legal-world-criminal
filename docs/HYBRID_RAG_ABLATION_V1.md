# Hybrid RAG R0—R4候选消融

本次在120条自动生成、待教师复核的qrels候选上比较五种检索条件。100条查询带候选正例，20条为明确不存在的法名和条号。结果用于选择工程架构和发现短板，不作为正式检索准确率。

| 条件 | Recall@5 | MRR@10 | NDCG@10 | 精确条号Top1 | 无答案误返回率 |
|---|---:|---:|---:|---:|---:|
| R0 BM25F | 0.8000 | 0.7484 | 0.7705 | 0.7500 | 1.0000 |
| R1 Dense | 0.8500 | 0.7823 | 0.8018 | 0.8750 | 1.0000 |
| R2 RRF | 0.8100 | 0.7807 | 0.8017 | 0.9167 | 1.0000 |
| R3 RRF + 条号/弃权保护 | 0.8300 | **0.7979** | 0.8152 | **0.9583** | **0.0000** |
| R4 R3 + Reranker | **0.8600** | 0.7940 | **0.8156** | **0.9583** | **0.0000** |

## 得到的工程结论

1. Dense必须使用结构化文本。向量输入从仅正文改为“来源类型+标题+条号/章节+正文”后，Dense候选Recall@5从0.62升至0.85；条号从0.2917升至1.0，司法文件从0.50升至0.8125。
2. Dense仍不能替代BM25F。精确法名和条号属于主键语义，必须保留词法检索与规则保护。
3. 单纯RRF仍不足。加入精确法名/条号保护和不存在法条弃权后，无答案误返回率才从1.0降到0。
4. Reranker有召回增益。在保护规则之后，整体候选Recall@5从0.83升至0.86；司法文件从0.6875升至0.8125。MRR轻微下降，因此后续教师Gold应同时关注Recall和首位排序。
5. 教材检索仍是短板。R4教材候选Recall@5只有0.45，说明需要教师补齐等价章节正例或增加教材查询扩展，不能对外宣称已经优化完成。
6. 精确条号Top1的0.9583不等于规则失败：自动qrels只标了单一来源，而同名同条号可能存在多个版本候选；正式评测需由教师补齐等价正例和时效判断。

## 当前选择

正式运行时采用R4：`BM25F + Dense → RRF → 精确法名/条号与弃权保护 → Reranker`。如果Embedding失败降级BM25F，如果Reranker失败降级保护后的RRF。

## 证据边界

这些查询和正例由索引语料自动构造，法学教师复核数为0。因此可用于调试、消融和比赛中的“实验协议/候选结果”展示，不能写成专家准确率、法律蕴含准确率或课堂学习效果。
