# 本科刑法课堂8—12人可行性试点协议

## 目的与结论边界

首轮8—12人试点只回答：系统是否可用、事件是否完整、教师能否解释学情、学生是否能完成“预习—精学—复习”旅程。样本不足以证明学习增益或自适应路径因果效果，结果只能用于迭代和后续正式研究设计。

50人试用不是本地工程动作，必须等待院校授权、任课教师、知情同意/伦理与隐私流程、有效学期法源复核、试点通过和预注册实验方案。

## 进入条件

1. 任课教师用内容复核台账完成本学期10个KnowledgeCard、30个TaskItem和3个CaseBundle复核；
2. 法源对照届时国家法律法规数据库有效文本，保存新快照与哈希；
3. 学生端、教师端、事件/画像/推荐、备份与退出流程通过本地冒烟；
4. 试点不接正式成绩，LLM只给形成性反馈；
5. 明确负责人、数据保存期限、访问角色、异常报告与撤回方式；
6. 班级聚合默认至少3人，任何导出不含API Key、JWT、密码、学生邮箱或困惑原文。

## 参与者与安排

- 8—12名自愿本科法学学生；不因参加与否影响课程成绩；
- 1名刑法任课教师，建议另有1名法学教师抽样复核反馈；
- 2周、3次接触：
  - 第0次（30—40分钟）：说明/同意、基线平行题、操作练习；
  - 第1周（45—60分钟）：课前知识卷宗与困惑→1个发布案例精学阶段；
  - 第2周（45—60分钟）：复习任务→平行后测→可用性访谈；
- 7—14天后可做短保持测验，但仍仅探索性报告。

## 数据最小化

使用随机研究ID与系统user_id映射；身份映射由院校/教师独立保管，研究导出只含研究ID。收集：

- TaskAttempt：任务/内容版本、选项、正确性、耗时、把握、提示/答案揭示、阶段；
- 精学：案例/阶段/Prompt/模型/法源版本、学生独立输入、评分与弃权、AI辅助资格；
- 困惑：优先分类与计数；原文只有在同意书明确且访问受控时才纳入研究导出；
- 系统：错误、延迟、重试、token/费用的脱敏聚合；
- 问卷/访谈：可用性、负担、反馈可理解性和教师工作量。

不收集与研究无关的身份证号、住址、通讯录、定位或其他课程成绩。

## 可行性指标

### 主要指标

- ≥80%参与者完成规定旅程；
- ≥95%规定学习动作生成结构有效、可关联版本的事件；
- 答案提前泄漏、跨学生身份写入、事件冲突静默覆盖均为0；
- 严重法律错误/虚构法源一经发现可追踪、停用和复核；
- 教师能在不看学生邮箱/困惑原文的情况下解释主要班级信号；
- 学生中位任务完成时间和系统错误率处于教师可接受范围。

### 探索指标

- 基线/后测/保持平行题的个体变化及不确定区间；
- 把握—正确性的校准误差；
- 不同知识点的完成、困惑和临时状态分布；
- 教师对反馈正确性、可操作性和工作量的评分。

8—12人不做“显著提高X%”结论，不按p值挑结果，不把`provisional`当掌握概率。

## 教师抽样与停止规则

- 每名学生至少抽查1条TaskAttempt反馈和1个精学阶段反馈；
- 主观反馈由两名教师对一部分样本盲评，记录分歧和弃权；
- 出现以下任一情况暂停对应内容或整个试点：真实凭据泄漏、跨学生数据、当前有效法引用错误、答案提前泄漏、无法撤回、严重误导反馈连续出现、教师认为继续有教学风险。

暂停后保留最小审计证据，禁止为了演示继续自动推进。

## 从试点到正式路径实验

试点通过后再设计L4实验：

- 对照“固定教师顺序”与“自适应顺序”，使用相同内容池、教师、课时和测量；
- 预先冻结主要结局、样本量/功效、随机或准实验分配、缺失处理、排除标准和分析代码；
- 使用未在训练/推荐中泄漏的平行测量，增加保持和迁移；
- 报告干预忠实度、教师覆盖、实际任务路径和所有不良事件；
- 只有这类证据才能讨论路径因果效果。50人是否足够必须由效应量、聚类结构和功效分析决定，不能把“50”当固定正确样本量。
