# 学生端连续学习旅程

切片C把KnowledgeCard、TaskItem、TaskAttempt、LearningEvent、LearnerProfile和Recommendation串成一个可操作的学生界面。入口位于登录后顶部“自主学习”，不改变原有六阶段案件精学工作台。

## 页面结构

页面采用“刑法学习卷宗”形态，而不是单独的通用仪表盘：

1. **知识卷宗索引**：展示10个课程核心知识点、章节、当前证据状态和覆盖进度；点击知识点会优先选择对应任务。
2. **当前知识简报**：展示学习目标、摘要、法条索引、标准Evidence数量、内容版本和教师门禁状态。
3. **任务卷页**：展示推荐原因、认知维度、难度、题干、选项与1—5级作答把握；支持多选，提交前可修改。
4. **判分批注**：服务端判分后才展示正确选项、解析、命中误概念、证据数量和下一任务入口。
5. **证据账本**：展示全部事件、合格证据、自报困惑，以及当前知识点的“3事件/2任务”临时画像门槛。
6. **任务序列**：展示不含答案的后续任务，并允许学生主动切换。
7. **困惑便笺**：按概念边界、规范理解、事实适用、证据使用或其他困惑分类提交；入账后影响推荐优先级，但不直接降低掌握状态。

课前预习和课后复习共用同一安全的TaskAttempt契约与事件模型，但在学生体验上是两种不同的学习任务：

- **课前预习：带着问题进入课堂。** 暖色入课问题单，以“浏览规则→完成摸底→标记困惑→带入课堂”为流程；右栏叫“入课准备/课前任务单”，困惑提示鼓励学生写下希望课堂解决的条件、事实或证据。
- **课后复习：用证据完成一次复盘。** 冷色证据复盘台，以“回看错因→核对Evidence→完成变式→安排再测”为流程；右栏叫“复盘证据/巩固与再测队列”，困惑提示聚焦规则边界、错因和证据缺口，并提供重写/角色互换入口。

两种阶段仍通过`phase`区分并共享审计契约，但不会把课前摸底文案伪装成课后成绩，也不会把课后复盘的变式任务当成第一次诊断。学习档案继续承担跨案件雷达、成长曲线和长期报告。

## 交互与证据规则

- 浏览器只获得公开TaskItem和Recommendation，不获得私有答案；
- 页面为每次新任务生成`attempt_id`，网络失败重试时保留该ID；
- 页面提交TaskItem的`content_version`，服务端拒绝旧页面答题；
- 学生答案、耗时、把握、阶段和辅助信息生成不可变LearningEvent；
- 提交成功后用服务端返回的画像和推荐原地更新页面，已答任务从任务序列移除；
- 困惑使用独立`annotation_id`，不能伪装成知识答错证据；
- `provisional`只代表形成性临时证据，页面明确提示它不是正式成绩或ORCDF掌握概率。

## 视觉与响应式

桌面端为“知识索引—任务卷页—阶段账本”三栏。预习使用赭金色问题单和暖色纸张纹理，复习使用蓝绿色证据台和冷色网格；两者的流程条、栏目名、按钮和提示语同步变化。1040px以下改为单列文档流：知识索引双列、任务居中、账本下沉；720px以下进一步压缩知识索引和操作区。账本不会在窄屏被隐藏，因此困惑标注与证据边界始终可达。

动画遵循`prefers-reduced-motion`，所有主要操作使用原生button/select/textarea语义；弹层支持Escape关闭。

## 本地验证

启动本地SQLite栈后运行：

```powershell
cd frontend
npm run build
npm run smoke:journey

$env:JOURNEY_VIEWPORT_WIDTH='900'
$env:JOURNEY_VIEWPORT_HEIGHT='900'
npm run smoke:journey
```

浏览器冒烟使用`playwright-core`复用本机Edge或Chrome，不下载浏览器。它会创建随机测试账号，并验证：

- 10个KnowledgeCard和可执行任务出现；
- 选择答案、服务端判分、反馈和下一任务可见；
- 困惑可归入证据账本；
- 页面不出现三个私有字段名；
- 控制台、页面异常、HTTP错误和请求失败均为空；
- 输出桌面或指定视口截图到被Git忽略的`.codex-artifacts/`。

阶段差异化门禁还会验证课前/课后标题和强调色不同、切换后各滚动栏回到顶部，以及题干字号≥18px、选项字号≥15px，以保证1500×980录屏可读。脱敏展示截图与机器报告见`competition_submission/03-Demo/learning-phases/`。

## 当前边界

- 当前可执行任务包括30道选择诊断题、10个知识点主观短答和3个CaseBundle角色互换任务；主观分数与长期画像仍必须经过教师批准。
- AI分层解惑已接入受治理Evidence、诊断追问和确定性fallback，但解惑不计分、不生成LearningEvent；尚无真实学生的可理解性、纠错效果或保持迁移证据。
- 尚未实现正式考试的时段、监考、延迟公布答案和成绩确认。
- 当前推荐器会按证据、先修和完成状态重排候选任务，课后界面提供变式/重写入口；尚无正式间隔算法、真实题目参数校准或路径干预效果评估。
