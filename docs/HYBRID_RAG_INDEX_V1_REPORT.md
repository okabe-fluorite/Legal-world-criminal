# Hybrid RAG三库索引构建报告

三套本地索引已经完成，可供下一阶段的BM25F、Dense、RRF和Reranker混合检索使用。

| 索引 | 数量 | 用途 | 答案隔离 |
|---|---:|---|---|
| 法律与案例 | 54,463块 | 法律、行政法规、司法文件和案例子块检索 | 不涉及题目答案 |
| 教材解释 | 1,404块 | 原理解释、章节定位和教学补充 | 与法源权威层分开 |
| 公开题目 | 1,184题 | 相似题、章节匹配和练习推荐 | 不含答案、解析、Rubric和错因私有字段 |

共处理57,051条可检索记录，调用Embedding 1,783次。向量均为1024维、归一化float16；每个集合同时具有SQLite FTS5词法索引，通过字段权重实现BM25F式检索。当前有效索引约511MiB，位于Git忽略的本地生成目录。

## 设计结果

- 法源、教材和题目物理分库，避免教材覆盖现行法；
- 案例只索引短子块，命中后按父段回填完整案情或裁判规则；
- 公开题目采用题干和选项生成向量；
- 私有题目索引明确禁用，不向Embedding服务发送答案或解析；
- 构建过程按批次落盘，可中断后继续；
- 索引文件、全文元数据与第三方材料不提交Git。

## 下一阶段

运行时链路为：

```text
BM25F + Dense并行召回
→ RRF融合
→ Qwen3-Reranker-8B重排
→ 精确法名/条号保护
→ 案例父段回填
→ 来源、时效和引用检查
```

Embedding失败时保留BM25F，Reranker失败时保留RRF结果。精确法名和条号命中不会因语义重排被移出结果。

## 证据边界

“索引可用”只表示记录数、向量维度、元数据行数和词法索引行数一致。自动qrels尚待法学教师复核，因此当前不把索引构建称为检索效果、法律蕴含或课堂学习效果。
