# 多来源RAG自由检索与行末引用

## 目标

“可信RAG”页面除3个固定典型问题外，现提供可实际输入问题的“自由检索”模式。它把后端多来源EvidencePack直接投影为学生可理解的五类用途：

1. 规范依据：法律、行政法规；
2. 司法适用：司法解释、司法规范性文件；
3. 案例参考：指导性案例、典型案例；
4. 教材解释：课堂和学理说明；
5. 下一步练习：公开相似题和诊断任务。

低层级材料不能覆盖高层级规范；公开题不参与法律结论证明；私有答案层不进入检索或Embedding。

## 用户链路

1. 登录后点击“可信RAG”；
2. 切换到“自由检索”；
3. 输入问题或选择五类来源的快速验证问题；
4. 前端调用`POST /api/knowledge/search`，同时检索`legal_authority`、`textbook_explanation`和`question_public`；
5. KnowledgeCard自动匹配知识点，并用知识点名称、法条锚点和先修节点扩展Hybrid查询；
6. 页面按`allowed_usage`分组，每段正文末尾显示来源编号；
7. 悬停显示截断摘要，点击打开完整来源详情；
8. 案例显示父段上下文，`unresolved`显示“效力尚未完全核实”；
9. 明确不存在的法名和条号不返回相近伪答案。

普通界面不显示内部Evidence ID、检索分数、SHA、向量位置或降级机器码。

## Graph × RAG分工

- 课程知识图回答“学什么、先学什么、下一步做什么”；
- Hybrid RAG回答“依据是什么、原文在哪里、来源能承担什么用途”；
- KnowledgeCard节点、条号和先修关系用于查询扩展；
- 多来源Evidence反向支撑诊断解释和路径推荐；
- 图谱与检索命中均不单独证明学生掌握、法律蕴含或路径因果效果。

## 真实浏览器验证

验证脚本：

```powershell
cd frontend
node scripts\smoke-multisource-rag-explorer.mjs
```

已在1500×980和780×900分别运行真实浏览器、真实本地HTTP和当前Hybrid索引。两种视口均完成：

- 法律：行末引用、当前版本、规范依据；
- 司法文件：司法适用身份、最高检察院发布机关、效力尚未完全核实提示；
- 案例：案例身份、裁判参考用途、检索子块命中后的父段；
- 教材：教材解释身份、版次待补充、不得覆盖现行法；
- 公开题：学习资源身份、相似题用途、法律效力不适用；
- 不存在法名/条号：可见引用0，可靠弃权；
- 已废止材料：显示“已废止”并提示不得作为现行法依据；历史/被替代材料同样只用于沿革或比较；
- Graph×RAG：正当防卫节点、第二十条与“犯罪概念与但书”先修关系可见；
- 私有答案与内部字段泄漏0；
- 横向溢出0；console/page/HTTP/request错误0。

对应本地证据位于`.codex-artifacts/multisource-rag-explorer-wide/`与`.codex-artifacts/multisource-rag-explorer-narrow/`，不提交合成账号或运行数据库。

## 当前边界

- 这是多来源检索与引用呈现，不是正式法律意见；
- 候选相关性不等于法律蕴含；
- 363份效力尚未完全核实的官方原件可检索，但必须保留效力提示；
- 教师qrels复核仍为0；
- 真实刑法课堂知识追踪校准和路径干预效果仍需课堂纵向数据。
