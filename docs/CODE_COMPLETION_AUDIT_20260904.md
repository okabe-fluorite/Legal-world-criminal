## 官方来源资料的运行口径

- 国家法律法规数据库等官方来源原件默认可进入检索候选和EvidencePack，不因缺少详情页或个别日期字段而隔离；
- 363份效力字段待完善材料显示“效力尚未完全核实”，该提示是非阻断元数据说明，不是来源不可信结论；
- 不把它们自动包装成已确认现行有效规范；
- 模型输出必须保留效力提示，并优先使用已核实的高层级现行规范；
- `verified_historical`、`superseded`和`repealed`只用于沿革、旧案或比较，不能单独支持现行法结论；
- 若只有未核实、历史、被替代或废止材料，系统应弃权或提示核对最新官方文本；
- 国家库详情页或官方机关信息与模型判断冲突时，以官方信息为准。
- 不再继续对363份材料逐份追网页或调用模型核实；后续只做版本增量刷新和明确异常抽检。
