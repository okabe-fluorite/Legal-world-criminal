# 无课堂历史数据下的递归先修路径

## 问题

新课程没有长期课堂作答时，系统不能把未经校准的模型概率冒充掌握度，也不能因为某个高级知识点答错就机械重复同类题。当前实现采用Evidence-KT保守状态与KnowledgeCard先修图，先回答两个问题：

1. 当前观察到的薄弱目标是什么；
2. 为处理该目标，最根部尚未满足的先修是什么。

## 当前策略

策略版本：`graph-aware-evidence-cold-start-v2`。

### 冷启动

- 没有任何合格事件时，30道选择题按10个知识点进行覆盖诊断；
- 每个知识点先分配一题，避免只在一个章节连续抽题；
- 学生自报困惑只提高当前知识点优先级，不作为负掌握证据；
- 公开推荐不含答案、解析和误概念私有字段。

### Evidence门槛

- `insufficient_evidence`：证据尚不足；
- `provisional`：至少3个合格事件且覆盖2道不同任务；
- 只有`latest=mastered`且`evidence_status=provisional`的先修节点才视为已满足；
- 状态仍不是校准掌握概率，不用于正式成绩。

### 递归先修前沿

当客观LearningEvent把目标标为`missing`或`partial`时：

1. 从目标KnowledgeCard读取`prerequisite_ids`；
2. 递归向上寻找尚未满足的先修链；
3. 选择最根部的未满足节点作为下一题目标；
4. 在Recommendation中返回完整`prerequisite_path_names`；
5. 根节点达到3事件/2题门槛后，重新计算并解锁下一层；
6. 所有先修满足后，再回到原薄弱目标。

示例：

```text
观察到薄弱：故意、过失与意外事件
先修链：罪刑法定原则 → 犯罪概念与但书 → 故意、过失与意外事件
下一题：罪刑法定原则
```

学生主动报告当前目标困惑时，系统会先直接回应困惑，不强制把自报信号解释为失败；后续客观作答再决定是否回退先修。

## 判分修正

选择任务使用`exact_option_set`：

- 完全等于正确选项集合：`mastered`；
- 所选集合是正确集合的真子集，即只漏选、没有混入错误项：`partial`；
- 混入任一错误项或完全不命中：`missing`。

这样可避免“把所有选项全部勾上”因包含正确项而获得partial状态。

## 前端闭环

- 自主学习任务单按全局自适应顺序展示，不能因用户当前打开某个知识卷宗而过滤掉跨知识点先修推荐；
- 推荐原因显示完整先修链；
- 点击“进入下一任务”会真正进入最根部先修题；
- 认知诊断七步路径分别显示：观察到的薄弱目标、递归先修链、实际下一题；
- 选择题完成后重新请求Recommendation，不预写固定路径。

## 验证

自适应专项13项通过，包括：

- 10知识点冷启动覆盖；
- 客观薄弱触发递归先修前沿；
- 根节点3事件/2题后解锁下一层；
- 困惑直接优先但不进入负掌握；
- 全选混入错误项记为missing；
- 已答任务排除、答案隔离、幂等与冲突检查。

真实浏览器脚本：

```powershell
cd frontend
node scripts\smoke-graph-aware-path.mjs
```

浏览器实测从“故意、过失与意外事件”错误作答开始，系统返回：

- 观察目标：故意、过失与意外事件；
- 下一先修：罪刑法定原则；
- 完整链：罪刑法定原则 → 犯罪概念与但书 → 故意、过失与意外事件；
- 自主学习队列和认知诊断七步路径均显示同一链；
- 私有字段、console/page/HTTP/request错误均为0。

机制审计`docs/PRODUCT_EVIDENCE_AUDIT.json`对10个知识点验证：有先修时回退递归前沿、无先修时直接补目标，10/10通过；困惑信号仍使10/10报告知识点排在第一。

## 边界

- 当前图只有10个刑法核心节点和10条教师/项目先修边；
- 递归顺序是可解释教学规则，不是由真实课堂干预证明的因果最优路径；
- 没有真实题目参数、时间衰减和正式间隔重复模型；
- ORCDF仍只作民法/宪法shadow，不进入当前刑法学生画像。
