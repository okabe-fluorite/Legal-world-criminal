# 产品消融与证据分级协议

本协议把“软件机制工作”“教师认为反馈可用”“学生真的学会”“路径产生因果效果”分成四级证据，禁止用低级证据替代高级结论。

## 证据等级

| 等级 | 问题 | 当前可用证据 | 禁止外推 |
|---|---|---|---|
| L1 软件机制 | 接口、检索、排序、权限、答案隔离是否按代码工作 | 单元/HTTP/浏览器E2E、`PRODUCT_EVIDENCE_AUDIT` | 学习增益、效度 |
| L2 内容与反馈质量 | 法源、题目、Rubric、反馈是否被教师认可 | 每学期内容复核、双评、抽样错误分析 | 学生掌握、路径因果 |
| L3 学习测量 | 学生前后测、保持和迁移是否改善 | 真实课堂纵向数据、平行题、题目参数/校准 | 自适应策略因果优势 |
| L4 路径效果 | 自适应路径是否优于对照 | 预注册随机/准实验、同测量、干预忠实度 | 跨院校泛化 |

当前仓库具有较强L1和少量机器门禁L2准备，不具有L3/L4证据。

## A. 可信检索与EvidencePack

固定输入为10个KnowledgeCard的名称+摘要，预期法条为`law_article_refs`，法源快照和manifest哈希必须冻结。

- A0：仅BM25 top-5；
- A1：BM25 + KnowledgeCard标准Evidence ID；
- 指标：expected-article hit@5、条号有效率、逐字片段匹配率、coverage诚实状态；
- 不测：claim-level法律蕴含、争议观点正确性。

当前确定性审计结果：A0 expected-hit@5=90%，A1=100%，22条Evidence条号/逐字片段22/22。A1提升只说明受治理证据绑定补足了一条课程查询的候选召回，不能称“法律推理准确率提高”。

## B. 自适应排序机制

固定30道TaskItem、10个知识点和同一冷启动策略版本。对每个知识点独立创建隔离的合成软件测试账号：

- B0：无学习证据的冷启动排序；
- B1：写入一条canonical `missing`事件；
- B2：写入一条独立`confusion_annotation`；
- 附加门禁：已完成任务排除、推荐私有字段0、同ID幂等/冲突。

指标是目标知识点首题排名变化，不是学生表现。当前B1/B2均使10/10目标到第1位，平均前移4.5位；这只证明策略响应信号。

真实路径效果必须在L4试验中比较：同前测、同内容池、同教师、同课时下，“自适应顺序”与“固定教师顺序”的后测/保持/迁移，不得用本机制测试代替。

## C. Agent精学

当前已有真实六阶段工程E2E，但尚未执行可归因的Agent消融。后续实验必须固定：

- 同一发布CaseBundle版本、相同学生预置回答、同模型/温度/Prompt版本、同法源快照；
- C0：静态材料+固定阶段提示，无对抗Agent追问；
- C1：完整阶段角色Agent、工具权限、对抗反馈；
- 输出：流程完成率、引用错误、涵摄要件覆盖、教师盲评质量、运行时故障、token/时间成本；
- 至少两名法学教师独立盲评，报告一致性和弃权，不以LLM自评作为金标。

在这组同条件结果完成前，`REAL_E2E_AUDIT.md`只能证明Agent链路可运行，不能证明优于静态学习或提高成绩。

## D. 模型路由与微调模型

- D0：主模型单路由；
- D1：主模型+仅瞬态错误fallback；
- D2：指定任务使用约10B微调/本地模型，法源仍走受治理RAG；
- 固定独立金标准集、Prompt、RAG输出和任务输入；
- 指标：结构成功率、引用忠实度、教师盲评分、弃权率、延迟、token/费用、错误回退率。

当前单元测试已经证明瞬态fallback、共享熔断、非瞬态错误不回退和脱敏catalog；真实模型消融尚未在同一金标准集上运行。微调模型未达到独立验收前不得进入正式评分路由。

## E. 完整产品审计命令

```powershell
uv run --isolated --with-requirements requirements.lock.txt -- python -X utf8 `
  backend\scripts\run_product_evidence_audit.py
```

输出：

- `docs/PRODUCT_EVIDENCE_AUDIT.json`：逐知识点、哈希、排名和检查；
- `docs/PRODUCT_EVIDENCE_AUDIT.md`：人可读摘要。

脚本网络调用0、LLM调用0、课堂记录0；失败门禁会返回非0退出码。Agent与真实模型尚未运行的消融在JSON中显式为`false`，不能通过缺字段或文字包装成已完成。
