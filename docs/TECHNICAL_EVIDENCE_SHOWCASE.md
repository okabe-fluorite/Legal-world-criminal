# 技术说明页

## 目的

“技术说明”页面把数据治理、2024刑法版本、结构化推理检查、LegalEduEval、Agent对比和轻量2D导师结果投影到真实Demo，满足3分钟视频中直接说明学科数据、结构化推理、模型评测与Agent实验的要求。

它是比赛、答辩和队友验收用的只读技术说明，不是学生学习页面：用于把“数据→来源→推理→评测→应用”的主线和下一步事项集中呈现；它不参与学生作答、评分、LearningEvent或长期画像。普通界面不展示SHA、内部ID、文件名或机器状态码，这些细节只保留在后端报告。

页面不是第二套事实源。`GET /api/competition/technical-evidence`每次读取6份权威JSON/manifest、重算SHA，并只返回计数、状态、成本、哈希和证据边界。

## 安全投影

API不返回：

- 完整C0/C1模型推理文本；
- Agent盲评内部A/B映射；
- 教师参考、典型错误和题目私有答案；
- 学生作答原文、邮箱或用户ID；
- API Key、鉴权头、完整本机路径。

任何审计文件缺失、JSON损坏或无Schema时，接口返回503，不用前端旧常量伪装成功。
