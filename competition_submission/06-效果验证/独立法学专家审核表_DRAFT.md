# 三个典型问题独立法学专家审核表（DRAFT·不得代填）

## 审核人

| 字段 | 填写 |
|---|---|
| 姓名/审核人编号 | `[审核人本人填写]` |
| 单位与专业方向 | `[审核人本人填写]` |
| 职称/年级与资格说明 | `[审核人本人填写]` |
| 审核日期 | `[YYYY-MM-DD]` |
| 利益冲突 | `[无/说明]` |
| 审核包manifest SHA-256 | `[从专家审核包_MANIFEST填写]` |
| 系统Git commit | `[填写]` |
| 模型/Prompt/run ID | `[填写]` |

“独立”指未参与本题系统输出、标准答案草案或门禁规则的生成；最低资格为刑法相关课程教师/研究人员、具有相关执业经历的法律专业人士，或团队能向评委说明其专业胜任力的同等审核人。法学研究生可作为第二审核人，但不得单独表述为“专家背书”。

审核分两阶段且不得覆盖：A阶段使用《审核表_A阶段》独立判断；A表签名与时间锁定后，B阶段才收到标准答案草案和自动门禁，并填写《差异复核表_B阶段》。两阶段表各自有签名、日期与文件SHA。

## 表单组成

1. `独立法学专家审核表_A阶段_DRAFT.md`：问题、系统输出和权威来源的盲判。
2. `独立法学专家差异复核表_B阶段_DRAFT.md`：标准答案/自动门禁揭示后的差异与最终发布结论。
3. `专家整改复签记录_DRAFT.md`：旧run、新run、整改项、重跑门禁和复签链。

## 整改与复签

如任一题结论为“修改后发布”或“拒绝发布”：旧输出和A/B表不可覆盖；团队生成新run并更新审核包manifest；使用《专家整改复签记录》由同一审核人或另一名合格审核人复核。只有复签为“可发布”的版本进入PPT和视频。
