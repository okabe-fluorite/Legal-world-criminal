# 星火智学伦理与安全合规声明（DRAFT·待签字）

## 一、项目用途

星火智学面向本科刑法课堂，提供形成性认知诊断、可信法源检索、个性化学习任务、多智能体案件实训与教师复核。系统用于教学支持与比赛演示，不替代任课教师、司法机关或执业律师，不自动发布正式成绩或法律意见。

## 二、数据来源与最小化

1. 法律文本来自受治理的本地法源快照，保存来源、版本和SHA-256；进入真实课堂前按届时有效法复核。
2. ORCDF实验使用MOOCCubeX民法/宪法匿名行为数据，只用于迁移研究和shadow展示，不冒充刑法课堂学生数据。
3. 演示账号使用虚构邮箱和本地SQLite数据，不录入真实身份证号、学号、联系方式或敏感案件当事人信息。
4. 用户试用只收集完成比赛验证所需的角色、年级/教龄、场景、时长、任务、评分和反馈；公开材料优先使用参与者编号。
5. 签名同意书与去标识试用记录分开保管；仅负责人和指定证据管理员可访问签名原件。原始记录在比赛结果公布后90天删除，最长不超过180天；参与者可通过`[团队填写撤回联系方式]`申请撤回，团队在7天内删除未公开原始记录。

## 三、AI生成内容与教师责任

- 页面和材料显著标注AI生成或AI辅助内容。
- 大模型只提供追问、解释、对抗与形成性反馈草稿；主观题只有教师批准后才形成长期画像证据。
- 错条号、伪造引文、越界Evidence和低置信度输出必须拒绝、弃权或进入教师复核。
- 当前微调端点未连接；不得将Prompt/RAG基线表述为已完成LoRA/SFT。

## 四、认知诊断与推荐边界

- `insufficient_evidence`表示证据不足；`provisional`表示临时证据状态，不是校准掌握概率。
- 困惑是学生自报信号，不直接作为答错或扣分证据。
- ORCDF mastery是未校准潜变量；个性化路径是可解释候选排序，不宣称因果最优或学习增益已验证。

## 五、安全与隐私措施

- API Key、Token和私有端点不进入前端响应、截图、PPT或Git。
- 学生历史和主观稿按登录身份隔离；教师只查看自有班级匿名形成性数据。
- LearningEvent不可变且幂等；同一主观稿最多一次教师决定和一次画像事件。
- 演示录屏不得显示邮箱、内部用户ID、访问令牌、密钥、私有绝对路径或未授权困惑原文。
- 比赛录制前由指定法源复核人记录法源快照日期、manifest SHA和复核日期，不只在真实课堂前更新。

## 六、风险与处置

| 风险 | 处置 |
|---|---|
| 法条过期或引用错误 | 版本化法源、逐字quote门禁、教师复核、失败弃权 |
| 模型偏见或不稳定 | 独立金标准、专家审核、低置信度回退、保留模型与Prompt版本 |
| 误把形成性评价当正式成绩 | UI、PPT和报告持续标识；不接正式成绩发布 |
| 学生画像误判 | 证据不足优先、事件可追溯、允许教师解释与学生修订 |
| 用户试用隐私泄漏 | 知情同意、最少字段、参与者编号、限定访问和保留期限 |
